# Loan Approval Prediction Dashboard

# Project Overview

The Loan Approval Prediction Dashboard is a web-based application that predicts whether a loan application is likely to be approved or declined.

The system analyzes factors such as income, credit score, loan amount, loan purpose, employment status, marital status, and education status to calculate an approval probability.

# Objectives

- Predict loan eligibility.
- Calculate loan approval probability.
- Provide quick and consistent results.
- Visualize prediction results using charts.
- Track approved and declined applications.

#  Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js

# How It Works

1. Enter the applicant's income.
2. Enter the credit score.
3. Enter the loan amount.
4. Select the loan purpose.
5. Enter employment, marital, and education status.
6. Click **Check Eligibility**.
7. The system calculates a score and approval probability.
8. The result is displayed as **Approved** or **Declined**.
